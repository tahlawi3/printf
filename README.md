# Description

ft_printf is a 42 project that recreates the printf() function using variadic arguments.

Supported conversions:
%c %s %p %d %i %u %x %X %%

# Instructions

Compile the library:

make

Clean object files:

make clean


Remove everything:

make fclean


Rebuild:

make re
